# Heart Disease Prediction

## Project Overview

This project uses machine learning to predict whether a person is likely to have heart disease based on various health-related features.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Machine Learning Model

- Logistic Regression

## Project Steps

1. Loaded the dataset
2. Explored the data
3. Checked for missing values
4. Performed data preprocessing
5. Split the data into training and testing sets
6. Trained a Logistic Regression model
7. Evaluated the model

## Results

The Logistic Regression model achieved an accuracy of 86.31% on the training data and 78.69% on the testing data. 
The testing accuracy shows that the model can correctly predict around 79% of the cases on unseen data. 
The difference between the training and testing accuracy suggests that the model performs slightly better on the data 
it was trained on.

## Conclusion

The project demonstrates how machine learning can be used to predict heart disease using health-related data.
